# konstantin.digital

Personal site of Konstantin Ruge — a minimal one-pager: bio, work history, FAQ.

Built with Next.js 15, Tailwind CSS 4, and Uxum Grotesque. No CMS, no analytics — content lives in `content/projects.ts` and `content/faq.ts`.

```bash
pnpm dev    # develop
pnpm build  # production build
```
